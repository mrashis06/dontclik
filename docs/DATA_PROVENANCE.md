# Data and model provenance

The local phishing audit records four URL files and two SMS CSV files. They are not copied into this repository, and their redistribution rights have not been established. Tranco is a ranked domain list rather than verified benign URL labels. Phish feeds describe feed labels at collection time and may be stale or source-biased.

SMS sources label spam/ham, not confirmed fraud. The experiments found source prevalence differences, malformed rows, and a synthetic legitimate banking-alert false positive. Model files derived from the corpora may retain data-derived vocabulary; treat them as unreviewed artifacts until license/privacy review. Record source URL, version/capture date, license/terms, SHA-256, schema, filtering, label mapping and consent/privacy status before approving any dataset or model for publication.
